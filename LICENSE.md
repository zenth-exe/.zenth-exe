## 🔧 Common Issues and Fixes

**❌ Problem:** The tool fails to load scripts on Windows.
> Solution: Run Zenth Executor as an administrator. This often resolves permission-related blocking.

**❌ Problem:** Scripts imported from Pastebin do not execute.
> Solution: Ensure the Pastebin URL is set to "raw" mode. The tool does not support regular Pastebin views.

**❌ Problem:** The Android version crashes on launch.
> Solution: Clear the app's cache and data, then reinstall. Also verify that your device meets the minimum requirements.

**❌ Problem:** Auto-execute does not trigger.
> Solution: Check that the target game or application is running in the foreground. Auto-execute only activates on active windows.

**❌ Problem:** The UI appears distorted on Windows.
> Solution: Adjust your display scaling settings to 100% or 125% and restart the application.

**❌ Problem:** Changelog does not show the latest version.
> Solution: Manually check for updates via the Settings menu or download the latest version from the official source.

**❌ Problem:** The tool cannot find script files on Android.
> Solution: Grant storage permissions manually through your device's app settings.
